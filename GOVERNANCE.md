# Governance and support

Maintainers review public API, schema and security changes. Shared releases must
pass Community and supported private-product compatibility tests before
promotion. Changes to these rules require an explicit maintainer decision.

Public issues are the place for reproducible Community bugs and proposals once
the repository is published. This candidate does not promise response times,
hosted service, availability guarantees or a commercial support contract.

Publishing the initial repository also requires an owner to name the maintainers
and enable a private security reporting channel.
